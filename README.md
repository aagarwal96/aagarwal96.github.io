# aagarwal96.github.io

Personal website, hosted at <https://aagarwal96.github.io/> through GitHub Pages.

## Publish

GitHub Pages serves files from `main` at repository root. Push a commit to `main`; GitHub publishes the updated static site automatically.

```sh
git push origin main
```

`index.html` contains page content. `styles.css` contains site styles. `.nojekyll` keeps deployment static with no Jekyll processing.
